# ForgePath Generated Icon System V1

Status: implemented private-alpha asset source

Generated: 2026-08-26

Source tool: built-in GPT Images

Usage basis: original ForgePath production asset generated for this repository from a project-specific prompt. No reference image or third-party icon set was supplied.

## Runtime exports

- `public/icons/navigation/`: five transparent 192 by 192 destination icons for Today, Plan, Progress, Library, and You.
- `public/icons/movements/`: twenty transparent 224 by 224 movement-family illustrations selected by the existing deterministic movement-art classifier.
- Movement names, family labels, and accessible text remain authoritative. The generated art is never the only carrier of exercise identity.

## Art direction

The system uses bold matte field-guide emblems with dark evergreen, bone, progress lime, and effort orange. It avoids thin generic icon-library outlines, gradients, drop shadows, copied game imagery, text, and runtime generation.

The navigation prompt requested five icons in a 3 by 2 transparent atlas: training calendar and plate, route map, ascending plates, open training guide, and athlete bust. The movement prompt requested twenty exact row-major families in a 5 by 4 transparent atlas, from flat bench press through a standalone dumbbell.

## Processing history

The two untouched GPT Images atlas PNGs are preserved beside this note. Runtime icons were cropped from their assigned grid cells, alpha-trimmed, padded onto square transparent canvases, resized with Lanczos sampling, and PNG-optimized. The original atlas files remain the audit source.

## Quality boundary

The contact sheet and mobile UI must be reviewed at full size and at actual navigation and Library rendering size. Reject any icon that becomes ambiguous, clips, creates horizontal overflow, obscures text, or makes a family illustration appear to be an exact variation-specific technique demonstration.
